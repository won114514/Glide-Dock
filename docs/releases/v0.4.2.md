# Glide-Dock v0.4.2

本次更新重做设置中心与安装向导，并修复普通权限启动安装程序失败的问题。

## 安装程序

- 使用 Microsoft Fluent UI React v9 与官方 SVG 图标，重新设计步骤导航、设置区和操作区。
- 统一标题栏按钮尺寸和对齐，支持浅色、深色、小窗口和高缩放。
- 修复仅以管理员身份运行才能打开向导的问题；需要系统权限的安装操作仍会按需请求 UAC 确认。
- 支持安装、更新和卸载；更新保留现有设置，卸载默认保留个人数据。
- 修复异步路径检查覆盖新输入、重复提交、进度回退和长错误信息显示问题。

## 设置中心

- 修复切换侧栏后旧选中状态残留。
- 调整卡片、下拉框、滚动区域与小窗口布局，补充滑块实时数值。
- 支持浅色、深色与跟随系统，并随显示器工作区和 Windows 缩放调整初始窗口。
- 分发包携带中文字体及许可证。

## 下载与安装

下载本页的 **Glide-Dock-v0.4.2-Setup.exe**。旁边的 `.sha256` 文件用于核验下载完整性。

- GitHub：https://github.com/won114514/Glide-Dock/releases/tag/v0.4.2
- CNB：https://cnb.cool/won114514/Glide-Dock/-/releases/tag/v0.4.2

支持 Windows 10 1809 或更高版本及 Windows 11 x64。安装向导需要 Microsoft Edge WebView2 Runtime；Dock 和 Slint 设置中心不依赖 .NET。
