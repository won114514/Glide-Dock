# Glide-Dock v0.4.3

本次更新完善 Dock 动效与帧调度，加入可切换的 GPU 硬件绘制，并改进安装、更新和卸载体验。

## 动画与 GPU 加速

- 优化高倍率悬停布局：保持图标顺序与固定分隔线，优先利用间隙；空间不足时平滑收缩放大增量，减少跳动和重叠。
- 统一动画状态快照与帧调度，按显示器刷新率运行；空闲时停止帧定时器，补齐启动失败回落和点击特效的结束帧。
- Windows 主 Dock 默认尝试 D3D11 + Direct2D 硬件绘制，并通过 DirectComposition 合成；设备或提交故障时自动回退 CPU 绘制。
- 「设置 → 外观」新增 GPU 加速开关，默认启用并记住用户选择；可通过 `GLIDE_DOCK_RENDERER=cpu` 强制 CPU 模式。
- GPU 绘制沿用现有 Dock 窗口，并按命中区域更新透明输入掩码，保留空白区域点击穿透；离线预览继续使用 tiny-skia。

## 安装与卸载

- 改进独立安装器与卸载器；安装器支持安装与升级，并保留现有设置和 Dock 条目。
- 仅允许版本更高的安装包升级，阻止同版本、降级及版本信息无法识别时覆盖安装。
- 改进普通权限启动、按需 UAC 提权、进度反馈和失败恢复；卸载完成后的残留清理以警告呈现，未完成时保留重试能力。
- 更新品牌图标及安装界面展示。

## 下载与安装

下载本页的 **Glide-Dock-v0.4.3-Setup.exe**；旁边的 `.sha256` 文件可用于核验下载完整性。

- GitHub：https://github.com/won114514/Glide-Dock/releases/tag/v0.4.3
