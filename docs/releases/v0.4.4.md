# Glide-Dock v0.4.4

本次更新加入 CNB 与 GitHub 双源自动更新，在保留用户确认环节的同时，减少手动下载、校验和覆盖安装的步骤。

## 软件更新

- 「设置 → 关于」显示当前版本、可用版本、两个发布源的检查状态、上次检查时间、下载进度、更新来源和发布说明。
- 启动时自动检查更新，之后每 24 小时检查一次；也可以随时在关于页手动检查。
- 同时查询 CNB 与 GitHub，按稳定版本号选择最新版；某个来源不可用时仍可使用另一个来源。
- 同版本优先使用响应更快的来源，下载或 SHA-256 校验失败时自动尝试备用来源。
- 安装包通过校验后缓存在本机；只有用户在关于页点击「确认并开始更新」才会启动安装。
- 便携运行不会自动覆盖程序文件，关于页提供 GitHub 与 CNB 发布页入口。

## 安装体验

- 自动更新通过预检后直接进入更新进度，跳过安装清单确认页。
- 保留原有设置、Dock 条目，以及必要时的 Windows 管理员确认。
- 安装包资源不完整、版本不允许更新或预检失败时明确显示原因，不会静默开始或反复等待。

## 下载与安装

下载本页的 **Glide-Dock-v0.4.4-Setup.exe**；旁边的 `.sha256` 文件可用于核验下载完整性。

- GitHub：https://github.com/won114514/Glide-Dock/releases/tag/v0.4.4
- CNB：https://cnb.cool/won114514/Glide-Dock/-/releases/tag/v0.4.4

支持 Windows 10 1809 或更高版本及 Windows 11 x64。安装向导需要 Microsoft Edge WebView2 Runtime；Dock 和 Slint 设置中心不依赖 .NET。
