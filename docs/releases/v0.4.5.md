# Glide-Dock v0.4.5

本次更新修复开机计划任务创建校验失败与权限继承问题，并新增内置管理员审批模式及管理员启动提示的原生界面弹窗。

## 计划任务与开机启动

- 修复 Windows 任务计划程序导出 XML 省略默认 `<RunLevel>`、`<Delay>` 并将 `<LogonTrigger><UserId>` 解析为 `域名\用户名` 导致的提权创建校验失败问题。
- 将计划任务执行主体调整为本地内置 `Users` 用户组（`S-1-5-32-545` / `TASK_LOGON_GROUP`），避免普通与受限管理员账号下计划任务错误以管理员权限启动。
- 写入计划任务与注册表兼容启动项前自动去除 `\\?\` 路径前缀。

## 权限与账号提示弹窗

- 使用与设置中心同源的自绘原生 Slint 窗口替代系统弹窗。
- 检测到使用内置 `Administrator` 账号且未开启「用于内置管理员账户的管理员批准模式」时，自动弹出引导窗口，提供 `secpol.msc` / `gpedit.msc` 组策略修改教程、家庭版命令行补充以及「打开本地安全策略」「复制命令」快捷操作。
- 检测到以管理员权限启动 Glide-Dock 时，弹出「检测到管理员权限」提醒窗口说明 UIPI 拖放限制并提供「退出 Glide-Dock」按钮。

## 下载与安装

下载本页的 **Glide-Dock-v0.4.5-Setup.exe**；旁边的 `.sha256` 文件可用于核验下载完整性。

- GitHub：https://github.com/won114514/Glide-Dock/releases/tag/v0.4.5
- CNB：https://cnb.cool/won114514/Glide-Dock/-/releases/tag/v0.4.5

支持 Windows 10 1809 或更高版本及 Windows 11 x64。安装向导需要 Microsoft Edge WebView2 Runtime；Dock 和 Slint 设置中心不依赖 .NET。
